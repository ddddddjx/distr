# 素材搜索 prompt

把下面这段整体交给带联网搜索能力的助手（或自己按关键词搜），产出一张可直接下载、可直接转码的素材清单。

---

我在给一个高尔夫挥杆姿态分析工具建精度验证集，需要你帮我找两类视频素材，并整理成表格。

## 需要的素材

**A. 职业选手标准机位挥杆（阴性对照，目标 20 段以上）**

- 机位只要两种：侧面（Down-the-line，镜头在球手身后沿目标线）和正面（Face-on，镜头正对球手胸口）。斜后方、俯拍、转播跟拍不要。
- 全身入镜（头到脚尖），固定机位，画面里只有一位球手。
- 挥杆前有至少 1 秒准备姿势静止。
- 正常速度和慢动作各找一些，慢动作请注明倍率。
- 球员尽量分散：不同身材、左右手、男女，避免全是同一位。把动作风格特别的球员（例如上杆路线明显特殊的）单独标出来。
- 优先来源：球员或品牌官方频道、赛事官方频道、有明确机位标题的教学频道。中文平台（B 站、抖音、小红书）如果有搬运的官方 Swing Vision 或 slow-motion 片段也可以，注明原始出处。

**B. 挥杆问题示范（阳性样本，每类目标 3 段以上）**

教练在视频里刻意示范"错误动作"的片段。需要这些问题，括号里是英文关键词：

- 早伸（early extension）
- 起身、失去姿势（loss of posture、standing up）
- 由外向内下杆（over the top、out to in）
- 髋部摇摆（sway）
- 髋部滑动（slide）
- 逆向脊柱倾斜（reverse spine angle）
- 重心滞留（hanging back）
- 鸡翅膀（chicken wing）
- 转肩过平（flat shoulder plane）
- 驼背圆肩站姿（C-posture）
- 站得太直 / 弯腰太多（posture too upright / too bent）
- 头部晃动、头部起伏（head sway、head drop）

要求同 A：标准机位、全身入镜、固定镜头。只要"错误示范"的那一段，标出它在视频里的起止时间。TPI（Titleist Performance Institute）官方或认证教练的 Big 12 讲解视频是最好的来源，中文搜索词可用"高尔夫 早伸 示范""高尔夫 起身 错误动作"等。

## 输出格式

一张表，每行一段素材，列：

| 编号 | 类型（pro / fault-规则名） | 机位（side / front） | 球员或教练 | 视频链接 | 片段起止（mm:ss） | 速度（正常 / 慢动作 x 倍） | 分辨率与帧率 | 来源性质（官方 / 教学 / 搬运） | 备注（个人特征、遮挡、镜头移动等） |

另外单独列出：

1. 你不确定机位是否标准的候选，我来人工筛。
2. 公开数据集线索。已知 GolfDB（McNally 等，2019）有约 1400 段职业挥杆并标注了 8 个关键事件帧，请确认它的获取方式、许可条款，以及有没有镜像或国内可达的下载途径。
3. 每个来源的使用限制。这些素材只做内部测试，不会进产品或公开仓库，但请标出明确禁止下载的来源。

## 下载与转码提示（供我自己用）

- 下载：`yt-dlp -f "bv*[height<=1080]+ba/b" -o "%(title)s.%(ext)s" <URL>`，只要片段可加 `--download-sections "*00:12-00:18"`。
- 转码：`ffmpeg -ss 00:00:12 -t 6 -i in.mp4 -vf scale=720:-2 -c:v libvpx -b:v 1.5M -c:a libvorbis out.webm`，开头多留 1.5 秒静止。
- 命名：`pro/side/<球员>-dtl-01.webm`、`pro/front/<球员>-fo-01.webm`、`faults/<规则码>/<机位>/<来源>-01.webm`，慢动作加 `-slomo`。
